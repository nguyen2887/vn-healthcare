# research/field — quan sát thực địa

Hộp thư thô cho người đóng góp (tester, triển khai, BA): mỗi quan sát một file theo `_TEMPLATE.md`, tên `YYYY-MM-DD-<chu-de-khong-dau>.md`. Viết bằng lời thường, không cần biết cấu trúc skill.

Agent (theo `skills/vn-healthcare/references/contributing.md`) sẽ đọc file này, hỏi lại cho đủ, rồi đề xuất sửa skill. File ở đây là **nguồn** cho mọi dòng `[THÔNG LỆ]`/`[HỎI]` sinh ra từ nó: dòng trong skill ghi "nguồn: field/<tên file>".
